## 书写过程数据授权协议

**甲方（数据提供者 / 书写者）**：〔姓名 / 匿名编号 W-xxxx；联系方式；签署日期〕
**乙方（数据接收与运营方 / 平台）**：〔主体全称；统一社会信用代码；数据保护负责人及联系方式；签署日期〕

鉴于乙方运营「婵娟 / e-Brush 书法交互系统」研发与教学演示项目，需要采集、保存并使用甲方书写过程数据用于模型训练、算法验证与教学反馈，双方在平等自愿基础上订立本协议。

### 第一条 定义

1. **过程数据**：指本协议适用数据清单所列、由甲方书写行为产生或被记录的全部数据及其衍生数据，包括笔端传感原始流、工程量序列、真值轨迹、墨迹图像、书写标注，以及由乙方或受托第三方从上述数据计算、训练、抽取所得的统计量、特征、嵌入（embedding）与模型参数中可关联识别到甲方的部分。
2. **匿名化 / 去特征处理**：指对过程数据实施技术处理后，使其满足：(a) 不能直接或间接识别到甲方个人身份；(b) 不能复原甲方的书写笔迹生物特征（动态签名特征）；(c) 处理规则与验证记录由乙方留存并可向甲方出示。仅去除姓名、编号不构成去特征处理。
3. **公开**：指将过程数据（含去特征处理后的样本）向不特定第三方提供，包括网络发布、数据集分发、API 开放与实体介质交付。
4. **副本不可追回**：见第五条第 3 款的专门约定。

### 第二条 授权模式（单选，签署时勾选）

- [ ] **模式 A：自留（self_only）**——数据仅由乙方为履约与本项目质量管控目的保存与处理，**不得用于任何公开，不得用于跨项目使用**。
- [ ] **模式 B：限时公开（timed_public）**——乙方在本协议约定的公开期限（起始日、截止日：〔 〕）内可为〔选项：模型训练与验证 / 研究成果发表与教学展示 / 数据集随论文发布〕使用并公开去特征样本；**期限届满后乙方应停止新的公开与分发**（存量按第五条第 3 款处理）。
- [ ] **模式 C：付费公开（paid_public）**——乙方可公开并商业性使用过程数据及衍生数据；甲方按第六条获得收益分配。
- [ ] **模式 D：永久免费公开（free_forever）**——乙方获得不可撤销的永久公开、再许可（限于去特征数据）与衍生使用权，甲方不取得收益分配。

授权模式可在任一模式下**向限制性更强的模式变更**（A > B > C/D 中取更严者），变更自乙方确认之日起生效，不溯及既往。

### 第三条 授权范围（用途、训练使用）

1. 除模式 A 另有排除外，乙方获得如下用途的非独占授权：
   (a) 存储、备份、迁移本项目采集的过程数据；
   (b) **平台训练使用**：训练、微调、评估与消融书法姿态估计、笔迹质量评价、教学反馈模型；训练所得模型可脱离原始数据独立部署与交付；
   (c) 为算法验证、演示与发表目的，使用**经去特征处理**的最小样例与统计图；
   (d) 委托第三方处理时，该第三方应受不低于本协议的保密与用途约束，乙方承担连带责任。
2. 超出上述范围的使用（商业授权给数据经纪、出售原始数据、可识别甲方的公开展示甲方笔迹作品等）须另行取得甲方单独书面同意。
3. 模式 B/C/D 下，公开对象为去特征处理后的数据或聚合统计；**原始数据（未去特征）仅在模式 C/D 且与可识别模型输出相分离的前提下**方可进入训练管线，训练产物中不得包含可还原甲方笔迹生物特征的显式样本存储。

### 第四条 去特征处理与数据边界

1. 乙方应对进入公开与分发环节的数据实施第一条第 2 款定义的去特征处理，并留存处理规则版本与验证记录。
2. 匿名化后的统计数据（不关联个体）不受第二条模式限制。
3. 真值链视频/深度影像中出现的甲方肖像、手部与书写内容影像，属可识别数据：公开前须单独取得肖像与内容使用的明示同意（可勾选：〔同意 / 不同意〕）。

### 第五条 撤回、副本不可追回与存续

1. 甲方可随时以书面或平台流程通知乙方撤回对**未公开、未分发数据**的使用授权；乙方应在〔7〕个工作日内停止对尚未分发数据的新使用，并应甲方要求删除，删除结果可复核。
2. 撤回自乙方确认之日起向将来生效，不影响撤回前已依约完成的合规处理行为。
3. **已公开并被他人下载的数据副本不可追回**。撤回仅作用于乙方及受托方控制下尚未分发的部分；乙方无义务也无能力从第三方处召回。甲方签署本协议即视为知悉并接受该规则。
4. 模式 B 期限届满：乙方停止新分发；**市场上已存在的合法公开副本不因届满而成为非法**，但乙方及其受托方不得再向任何新主体提供。
5. 数据集更新（v1→v1.1）时，乙方按届时甲方选定的模式处理新增数据，不溯及已发布版本。

### 第六条 收益与对价（仅模式 C）

1. 模式 C 下，乙方就包含甲方过程数据或其衍生数据的对外授权或销售所得净收入（扣除直接发生的渠道、税费与合理成本），按〔__%〕向甲方分配；分配按〔季度 / 单次结算〕，随附可审计的收入与成本明细。
2. 模式 D、A、B 无收益分配；模式 B 的对价为乙方提供教学反馈与研究成果署名机会（如适用）。
3. 聚合数据集（≥〔20〕名书写者且个体贡献不可分离）的商业使用，按上述比例整体计提，由甲方按其数据量占比受偿，或经甲方同意改用固定补偿：〔固定金额/方式〕。

### 第七条 甲方权利保留

1. 甲方对墨迹作品本身享有的著作权与人格权益不因本协议转移；本协议仅处分**数据层面**的使用授权。
2. 甲方有权随时查询乙方持有的本人数据类别、授权模式历史变更与去特征处理记录；乙方应提供可读清单。
3. 甲方有权要求对其数据衍生出的可识别展示（作品、画像、笔迹）事先取得单独同意（模式 B/C/D 适用）。

### 第八条 安全与合规

1. 乙方采取加密存储、访问最小化、操作审计与泄露应急响应；发生泄露时于〔72〕小时内通知受影响甲方并报告法定义务方。
2. 处理遵循《中华人民共和国个人信息保护法》《数据安全法》《网络安全法》及相关规定；涉及未满十四周岁未成年人数据的，须监护人单独同意并使用未成年人模式文本（另附）。
3. 跨境提供（如有）另行约定合规路径并写入附件。

### 第九条 期限、终止与存续

1. 本协议自签署之日起生效，至〔项目周期结束日 / 模式 B 截止日 / 永久（模式 D）〕终止。
2. 终止后，未公开、未分发数据按第五条删除规则处理；第五条第 3 款、第七条第 1 款、第八条安全义务与第十条争议解决在终止后继续有效。

### 第十条 争议解决与其他

1. 本协议适用中华人民共和国法律。争议先行协商；协商不成提交〔被告所在地人民法院诉讼 / 〔__〕仲裁委员会仲裁〕。
2. 本协议以纸质或可留存电子文本签署；变更须书面（含可存证电子形式）。未尽事宜签订补充变更单，编号顺延〔AGR-xxxx-001〕。
